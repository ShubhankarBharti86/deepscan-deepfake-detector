// Process

How DeepScan works

01 — UPLOAD

Image Ingestion

Drop any image file. DeepScan preprocesses it through a normalization pipeline — resizing, color-space conversion, and noise reduction.

02 — ANALYZE

Multi-layer Analysis

Four specialized models inspect facial geometry, frequency artifacts, GAN fingerprints, and lighting consistency simultaneously.

03 — VERDICT

Ensemble Voting

Model outputs are aggregated using a weighted ensemble. The final verdict and confidence score reflect agreement across all layers.

// Capabilities

What gets detected

🔎

GAN-generated Faces

Detects images created by Generative Adversarial Networks (GANs) such as StyleGAN, ProGAN, and DALL·E by analyzing pixel-level frequency patterns.

👥

Face Swap Detection

Identifies faces swapped using DeepFaceLab and FaceSwap tools by detecting blending mask boundaries and lighting inconsistencies.

⚡

Frequency Artifacts

Uses FFT (Fast Fourier Transform) analysis to expose compression artifacts and frequency anomalies invisible to the human eye.

🏭

Splice & Edit Detection

Detects copy-move forgery and image splicing using Error Level Analysis (ELA) and noise pattern inconsistency maps.
